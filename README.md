# resourcefootprints.com

Static site presenting EXIOBASE footprint results: a footprint explorer and the
EXIOBASE data-coverage comparison by release. Hosted on Cloudflare Workers
with static assets; Cloudflare builds and deploys every push to `main`.

## Layout

```
resourcefootprints/
├── site/                       ← DEPLOYED, all of it
│   ├── index.html              ← GENERATED from pages/index.html
│   ├── explorer.html           ← GENERATED from explorer_template.html + explorer-data.json
│   ├── explorer-sankey.json    ← GENERATED by build_explorer_data.py, fetched by the Flows tab
│   ├── coverage.html           ← GENERATED from 00-workflow/reference/coverage_page
│   ├── 404.html  _headers  robots.txt  sitemap.xml  favicon.svg
├── pages/index.html            ← SOURCE for the landing page
├── explorer_template.html      ← SOURCE for the explorer
├── build_site.py               ← pages + template + data -> site/*.html
├── build_explorer_flows.py     ← per-year MRIO (L, S, Y) -> explorer-flows.json
├── build_explorer_data.py      ← results cache + flows -> explorer-data.json, site/explorer-sankey.json
├── build_gro_sector_map.py     ← GRO 2024 Table A2.1 text -> gro2024_sector_groups.csv
├── gro2024_sector_groups.csv   ← EXIOBASE product -> GRO resource group and provisioning system
└── wrangler.jsonc              ← Cloudflare config: assets directory, custom domains
```

## Rebuilding

```powershell
cd D:\GitHub\resourcefootprints
python build_explorer_flows.py EXIOBASE_3_11_3   # only when the MRIO changes; about 6 minutes
python build_explorer_data.py                    # only when the cache or the flows change
python build_site.py                             # always; also picks up the 00-workflow coverage page
git add -A; git commit -m "..."; git push
```

- `build_explorer_flows.py` reads x, Y, L and S per year from
  `EXIOBASE_<release>/calculated/impacts/parquet/pxp` and computes resource-group
  splits (GRO 2024 Table A2.1, both where impacts occur and the footprint by
  originating group), consumption by product category, AWARE water stress,
  GLAM land-use and freshwater-eutrophication biodiversity loss, PM health, and
  sankey tensors for 1995, 2005, 2015 and 2024. It stops if any consumption total
  differs from pymrio's `D_cba_reg`.
- `build_explorer_data.py` reads exio_results' `impacts_pba_cba.parquet` cache and
  stops if the cached Global or Advanced rows are not the sum of their members,
  if the flow pass disagrees with the cache, or if categories do not sum to the
  consumption footprint. It writes non-combustion GHG as total minus combustion:
  the characterised `total non combustion` row in 3.11.2 and 3.11.3 misses SF6,
  HFC, PFC and NF3.
- `build_site.py` reads the coverage page from
  `D:\GitHub\EXIOBASE\00-workflow\reference\coverage_page` (its single source,
  shared with xio-sa.com and the Zenodo description) and the licence from the
  release package's `LICENSE.txt`.
- `gro2024_sector_groups.csv` is transcribed from UNEP IRP, Global Resources
  Outlook 2024, Methodological Annexes, Table A2.1; the source text is not in
  the repo.

The scripts need `pandas`, `pyarrow` and `numpy`; the flow pass holds about 1 GB
per year in memory.

## SEO

- Per-page `<title>`, meta description, canonical (apex, extensionless), `hreflang`
  en and x-default, Open Graph and Twitter `summary_large_image` cards with
  `site/og-image.png` (1200x630, from `make_brand_assets.py`).
- JSON-LD: `WebSite` and `Organization` on `/`; `WebApplication` and `Dataset` on
  `/explorer`; `WebPage` on `/coverage`. Written by `build_site.py`.
- `sitemap.xml` is regenerated by `build_site.py` with the build date; `robots.txt`
  points to it; `404.html` is `noindex`.
- Link to `/`, `/explorer` and `/coverage`, never the `.html` forms (Cloudflare
  redirects those).
- IndexNow: the key is the `<32 hex>.txt` file in `site/`; run `python ping_indexnow.py`
  after a deploy (Bing, Yandex, Seznam). Google needs Search Console.
- www: `www.resourcefootprints.com` serves the same pages. A Cloudflare Redirect
  Rule (dashboard, zone level) should 301 it to the apex, as on
  vectorsustainability.com.

## Copy

Page text states what is shown, with units and sources. No interpretation of
results, no calls to action.
